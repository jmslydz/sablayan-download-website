# Framework source and license

CodeIgniter 3.1.13 is included under its MIT license. See `license.txt` and the
headers in the framework files.

Official download information:
https://codeigniter.com/download

Official installation guide:
https://codeigniter.com/userguide3/installation/index.html

Exact framework source archive used:
https://codeload.github.com/bcit-ci/CodeIgniter/zip/refs/tags/3.1.13

The `system/` directory is copied without edits from that release. The
application-specific files, root configuration, and static assets implement
the Sablayan landing page. No generated application claims to be an official
release of the school or of CodeIgniter.
